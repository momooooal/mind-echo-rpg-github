# 一生的回聲 — Playable Life RPG v4

這版不再以「章節卡片 → 三選一 → 看解釋」作為主要玩法，而改成一個可移動、可錯過事件、以時間與日常行動為核心的生活 RPG。

## 核心玩法

- WASD / 方向鍵移動；E / Enter 互動。
- 手機版有螢幕方向鍵與互動鍵。
- 玩家可以靠近物件探索，也可以直接離開；不要求搜乾淨。
- 每次互動都會消耗同一條時間，公車、門診、工作不會替玩家停住。
- 線索可以永久錯過；後面的記憶重解讀只會在真的看過前置線索時發生。
- 求助不是強制劇情。高中沒去輔導室／沒有求助，遊戲仍繼續。
- 症狀沒有固定「職業路線」或疾病選單，以隱藏生活狀態與當日成本影響互動。
- 工作能力、吃飯、戀愛、病友群垃圾話與精神困擾並存。
- 結尾統計不是分數，只回看這一輪留下的日常痕跡。

## 可玩人生片段

1. 7 歲：凌晨客廳自由探索，童年線索可以錯過。
2. 12 歲：上學前的時間壓力與執行功能干擾。
3. 17 歲：放學後自由決定是否與同學、老師、輔導室互動。
4. 24 歲：工作、簡報與回診爭用同一個上午。
5. 33 歲：回家後的吃飯、洗澡、回訊息與「說不出口」。
6. 57 歲：病友群的普通聊天、垃圾話與偶發低潮。
7. 82 歲：普通午後與記憶回看。

## 隱私與內容界線

角色與群組內容皆為重新創作，不對應任何真實病友或群組成員。遊戲可以呈現精神困擾、污名、求助與生活成本，但不呈現具體自傷方法、不把危機做成勝負機制，也不提供醫療調藥建議。
